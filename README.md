# Partial Control: safe sets and safety functions

**Open the web app: [partialcontrol.github.io](https://partialcontrol.github.io/)**

Interactive web app for partial control of chaotic systems: safe sets and safety functions for 1D maps, 2D maps (including the Lorenz system on a Poincaré section) and 3D systems. It runs in the browser, on a computer or a phone, with nothing to install.

This repository holds the code of the page (`index.html`).
